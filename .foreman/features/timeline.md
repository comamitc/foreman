# Timeline

## Sub-features
- A read-only view of one delivery's action timeline; [timeline](../../references/modes/timeline.md) ("## Report") owns the report shape.

## How to get to it (user POV)
Install Foreman as [README](../../README.md) ("Install and invoke") describes, and invoke it from a workspace inside the repository.
[timeline](../../references/modes/timeline.md) ("This file owns the timeline invocation") owns the procedure.

## Driving it
Invocation: invoke Foreman with `timeline N`; [timeline](../../references/modes/timeline.md) ("The invocation is `timeline` followed by exactly one issue number") owns the grammar.
End state: [contract](../../references/contract.md) ("## Read-only invocations") owns what a read-only invocation leaves unchanged.

## Gotchas
- [timeline](../../references/modes/timeline.md) ("## Report") owns each gap line and what the view does not hold.
