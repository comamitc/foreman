# Contributing

## Rules

Each row pairs an authoring rule with the file that owns it and its enforcer, and cites the review findings that found it. Review applies every row to the plans and diffs it reviews.

| Rule | Owner | Enforcer | Occurrences |
| --- | --- | --- | --- |
| **Restated rule.** Review reads each sentence that a plan or diff adds outside the file that owns the rule the sentence concerns, and compares it with that owner's text; a reworded sentence, and a sentence next to an owner link, get the same comparison. Review reports each sentence that states behavior the owner's text already states, and cites that owner and its stable anchor. | [.capstan/vocabulary.md](.capstan/vocabulary.md) ("**Rule owner**") | review | #187 F2 @ 95dab44; #198 PR1 @ 8368a16; #207 F2 @ 61ced1d; #208 PR4 @ ebd36de; #209 F2 @ 33df6d4; #210 F5 @ 4199f58; #225 PR4 @ 6bf87ae; #226 F1 @ 23a36ba; #227 F1 @ 054a3e8 |
| **Misattributed owner.** For each owner link and quoted anchor that a plan or diff adds, review opens the owner at the quoted text and reads the sentence or section that holds it. Review reports the pointer when that text does not state the rule the pointer cites it for, even when the quoted phrase is present. | [.capstan/vocabulary.md](.capstan/vocabulary.md) ("**Stable anchor**") | review | #208 PR2 @ ebd36de; #209 F1 @ 33df6d4 |
| **Dropped inventory or case.** A procedure covers every item of the inventory it names, every part of the coverage its criteria require, and every case its criteria require. Review lists that inventory, coverage, and those cases from the criteria, looks for each one in the procedure, and reports each one it cannot find. | this file | review | #200 F2, F5 @ 592fced; #208 PR1, PR3 @ ebd36de; #209 F3, F4 @ 33df6d4; #210 F3 @ 4199f58; #229 PR1 @ 40a9bf6 |
| **Section contradiction.** No section of a mode contradicts another section of that mode, or an inherited rule that governs the mode, such as [SKILL.md](SKILL.md) ("Stop only at") or [references/contract.md](references/contract.md) ("## Stage projection"). Review compares each changed section with every other section of the mode and with each of those inherited rules, on the mode's empty, error, and stop outcomes as well as its main path, and reports each pair a run cannot follow together. | this file | review | #197 PR197-01 @ ce6e2a7; #208 R1 @ ebd36de; #210 F2 @ 4199f58 |
| **Trust order.** Review lists every text or history item a procedure consumes or retains: issue and comment text, and commit-derived items such as commits, reverts, and the PRs they come from. For each item, review opens the owner whose text covers that item kind and finds the procedure step that meets that text. Review reports each item that no step meets, and cites that owner and its stable anchor. | [references/security.md](references/security.md) ("Before consuming issue/comment text"); [references/planning.md](references/planning.md) ("author_association") | review | #200 F4 @ 592fced; #210 F1 @ 4199f58 |
