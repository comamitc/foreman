# Contributing

## Rules

Each row pairs an authoring rule with the file that owns it and its enforcer, and cites the review findings that found it. Review applies every row to the plans and diffs it reviews.

| Rule | Owner | Enforcer | Occurrences |
| --- | --- | --- | --- |
| **Restated rule.** Before the author of a plan or diff adds a sentence about a rule outside the file that owns it, the author opens that owner at its stable anchor ([.capstan/vocabulary.md](.capstan/vocabulary.md) ("**Stable anchor**")); the sentence names the owner and that anchor and states no behavior that the owner's text states. Review reads each sentence that a plan or diff adds outside the file that owns the rule the sentence concerns, and compares it with that owner's text; a reworded sentence, and a sentence next to an owner link, get the same comparison.
